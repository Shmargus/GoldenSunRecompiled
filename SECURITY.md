# Security Policy

## Sensitive data

Do not submit ROMs, BIOS files, save states, extracted assets, full memory dumps, or private filesystem paths in public issues.

## Reporting

For a vulnerability in original project code, provide the smallest reproduction possible using synthetic data. For an upstream `gbarecomp` vulnerability, report it to the upstream maintainer as well.

## Crash bundles

Crash/report tooling must default to metadata-only output. Memory ranges and user files are opt-in private exports and must never be uploaded automatically.
